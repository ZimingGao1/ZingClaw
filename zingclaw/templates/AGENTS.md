# Agent Instructions

## Workspace Guidance

Use this file for durable workspace-level guidance that should shape how the agent works in this project.

- Put repository workflow rules, architectural constraints, and recurring task conventions here.
- Keep personality and behavioral principles in `SOUL.md`.
- Keep user-specific preferences in `USER.md`.
- Keep long-term learned facts in `memory/MEMORY.md`, not here.

## Recommended Content

- Project goals and non-goals
- Code style or review expectations not already enforced by tooling
- Safe operating boundaries for this workspace
- Important commands, test flows, and release habits

## Notes

- Prefer instructions that stay valid over time.
- If guidance only matters for one task, say it directly in the conversation instead of storing it here.
