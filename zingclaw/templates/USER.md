# User Profile

Use this file for stable user preferences that should carry across sessions.

## Good Fits For This File

- Preferred language and tone
- Desired answer length
- Tooling or editor preferences
- Ongoing project context worth remembering

## Avoid Putting Here

- Secrets, tokens, and passwords
- One-off task instructions
- Large logs or temporary notes
